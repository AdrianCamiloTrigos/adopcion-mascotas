Cómo viaja una adopción

  1. El frontend envía la solicitud a la API de Adopciones.
  2. Adopciones pregunta a la API de Mascotas si el animal existe y no está adoptado.
  3. Guarda la solicitud y pide a Mascotas cambiar el estado a en_proceso.
  4. Al aprobar, Adopciones marca la solicitud y pide a Mascotas el estado adoptada. Si Mascotas falla, la aprobación se revierte.
  5. Las demás solicitudes pendientes de esa mascota pasan a rechazada.
